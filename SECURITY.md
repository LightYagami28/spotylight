# Security Policy

## Supported Versions

SpotyLight is a fork of Feishin. Fixes are developed on the `spotylight`
branch of this repository.

| Version | Supported |
| --- | --- |
| `spotylight` branch | :white_check_mark: |
| Earlier snapshots | :x: |
| Upstream Feishin | :x: (report here first) |

## Reporting a Vulnerability

Please do not file a public issue for a security problem. Email
<developer@lightyagami.dev> with:

- the component affected and the revision you tested;
- steps to reproduce, including a proof of concept if available;
- the impact on a self-hosted Navidrome or Subsonic setup;
- any mitigation you have already applied.

You should receive an acknowledgement within five working days. We will keep
the report private, prepare a fix in this fork and coordinate disclosure with
you. Please allow time for a fix before publishing the details.

Problems inherited from upstream Feishin are in scope here as well. We will
handle the fix locally and, where appropriate, relay the details privately to
the upstream maintainers. Do not open pull requests against upstream without
prior approval.
